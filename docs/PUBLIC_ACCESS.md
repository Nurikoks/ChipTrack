# Публичный доступ ChipTRick

Создан 18.10.2026. Используется Cloudflare Quick Tunnel к `http://127.0.0.1:8000`.

## Текущая ссылка

https://player-leg-routers-transmit.trycloudflare.com

- Сайт: `/`
- Готовность: `/health`
- Загрузка API: `POST /api/v1/analyze`
- Результат: `GET /api/v1/jobs/{job_id}`
- Заголовок API: `X-API-Key`; ключ в `runtime/api-key.txt`.

Актуальный адрес всегда находится в `runtime/public-url.txt`. Ссылка в этом документе относится к текущему запуску и изменится при создании нового туннеля.

## Как управлять

В `C:\Users\GGG\Desktop\datathon\ChipTrack-work`:

- `Start-Public.cmd`: запускает локальный сервер при необходимости и туннель в фоне. Если текущий туннель уже работает, повторно использует его адрес.
- `Public-Status.cmd`: показывает адрес, путь к журналу туннеля и результат публичного `/health`.
- `Stop-Public.cmd`: прекращает публичный доступ, оставляя локальный сайт работающим.
- `Stop-Background.cmd`: останавливает сам сайт. Не используйте во время проверки жюри.

Компьютер должен быть включён, не спать, иметь интернет; процессы сайта и туннеля должны продолжать работать. Закрытие окна запуска не завершает фоновые процессы. После перезагрузки откройте `Start-Public.cmd` и передайте новый адрес.

## Что передавать жюри

1. Актуальный HTTPS-адрес.
2. Ключ из `runtime/api-key.txt` отдельным сообщением/в согласованном канале. Административный пароль не нужен.
3. Инструкцию `docs/JURY_API.md`, заменив localhost публичным адресом.
4. Для интерфейса жюри может создать обычный аккаунт. Также подготовлен обычный демо-аккаунт: данные только в `runtime/jury-web-login.txt`. Это отдельный аккаунт, без права обучения/выпуска.

Не передавайте всему жюри администратора: он может проверять разметку, запускать обучение и выпускать версии. Если требуется показать админку, демонстрируйте её со своего компьютера.

## Маршрут данных и границы проверки

Браузер/API жюри → HTTPS Cloudflare → зашифрованный туннель → сервер на вашем ПК → локальные модели. Cloudflare является внешним сетевым посредником, через который проходят запросы и видео; это не облачный AI-анализ. Исходящие соединения туннеля не требуют открытия входящего порта роутера. Сайт продолжает требовать вход, API — ключ.

Пользователь разрешил проверку публичного адреса **только на искусственном видео**. Банковские ролики через этот туннель при подготовке не загружались. Отдельно согласуйте пригодность такого транспорта для тестовых данных жюри: локальное выполнение модели и отсутствие внешнего посредника — разные свойства.

Проверены публичные HTML/health, вход обычного демо-пользователя, HTTPS-cookie Secure/HttpOnly/SameSite, блокировка административных методов для обычного пользователя, отсутствие доступа к локальным файлам ключей, защита Origin и API с искусственным MOV. Данные проверки: `runtime/reports/public-smoke.json`.

Искусственный ролик дошёл до анализа; через 18,7 с API вернул `failed` / `insufficient_evidence`, поскольку на тестовом рисунке нет банковской сцены. Это подтверждает работу маршрута загрузки/очереди/ответа, но не качество выявления банковских нарушений. Проверка выполнена с этого компьютера через публичный адрес; независимый тест с отдельного устройства жюри ещё не проведён.

Quick Tunnel — временный демонстрационный доступ: нет гарантии uptime, имя меняется при новом запуске. Для постоянного адреса нужен именованный туннель с вашим доменом/аккаунтом либо постоянный сервер. Ограничения описаны в [официальной документации Cloudflare](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).
