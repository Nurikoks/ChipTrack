ПРОВЕРКА С ВАШЕГО КОМПЬЮТЕРА

Одно видео.
Четыре шага до ответа.

Загрузите видео через API, получите вердикт, тип нарушения, время события и кадры-доказательства. Вход на сайт для API не требуется.

PowerShell · WindowsАвторизация: X-API-KeyJSON + JPEG

Адрес и доступ

Сайт и API base URL:
https://loan-side-novels-twiki.trycloudflare.com

Ключ передаётся жюри отдельно через форму сдачи. В этом HTML ключа нет. Подставьте его вместо СЮДА_ВСТАВИТЬ_API_КЛЮЧ в шаге 1.

POST /api/v1/analyze
GET /api/v1/jobs/{job_id}
GET /health — без ключа

Адрес записан 18.10.2026. Временный туннель может сменить адрес при перезапуске. Если ссылка недоступна, запросите актуальный адрес у команды.

ШАГ 01

Указать данные

Откройте PowerShell на своём компьютере. Подставьте ключ, полученный от команды, и путь к вашему видео. Аккаунт на сайте не требуется.

powershell
$base = "https://loan-side-novels-twiki.trycloudflare.com"
$key = "СЮДА_ВСТАВИТЬ_API_КЛЮЧ"
$video = "C:\Users\Jury\Downloads\test.mov"
ШАГ 02

Отправить видео

Видео передаётся в multipart-поле file. Ответ содержит job_id — идентификатор задания. При ошибке загрузки сначала исправьте её, затем продолжайте.

powershell
$job = curl.exe --silent --show-error --fail `
  -X POST "$base/api/v1/analyze" `
  -H "X-API-Key: $key" `
  -F "file=@$video" | ConvertFrom-Json

$job
json
{
  "job_id": "example-job-id"
}
ШАГ 03

Получить результат

Если status равен processing, повторите эту команду через несколько секунд. Тот же ключ нужен и для загрузки, и для получения результата.

powershell
$result = Invoke-RestMethod `
  -Uri "$base/api/v1/jobs/$($job.job_id)" `
  -Headers @{"X-API-Key" = $key}

$result | ConvertTo-Json -Depth 20

Пока обработка продолжается:

json
{
  "job_id": "example-job-id",
  "status": "processing"
}
ШАГ 04

Сохранить полный ответ

После завершения анализа сохраните JSON с вердиктом и кадрами. Файл появится в текущей папке PowerShell; узнать её можно командой Get-Location.

powershell
$result | ConvertTo-Json -Depth 20 |
  Set-Content -Path ".\result.json" -Encoding UTF8
ФОРМАТ ОТВЕТА

Что вернёт анализатор

Условный сокращённый пример ответа с нарушением. Это иллюстрация формата, а не результат нового тестирования. В поле type передаётся название нарушения; внутренний код этой категории — T04.

json
{
  "job_id": "example-job-id",
  "status": "done",
  "verdict": "violation",
  "model_version": "rules-2.0-acd1be0e",
  "violations": [
    {
      "type": "Ключи оставлены в замочной скважине сейфа",
      "timecode_sec": 13.0,
      "description": "Ключ оставлен в замке сейфа после ухода кассира.",
      "evidence_frames": [
        {
          "timestamp_sec": 13.0,
          "image_base64": "...JPEG в формате base64..."
        }
      ]
    }
  ]
}
ПолеЗначение
status: processingОбработка продолжается; повторите запрос результата.
status: doneОбработка завершена. verdict: violation или no_violation.
status: failedОшибка или недостаточность доказательств. Причина находится в error.
timecode_secВремя события в секундах от начала ролика.
evidence_framesОт 1 до 3 кадров JPEG для события, закодированных в base64; timestamp_sec — время кадра.
model_versionВерсия модели, которая обработала загрузку.

При no_violation список violations пуст. Ответ failed / insufficient_evidence означает, что данных недостаточно для надёжного решения; это не ответ «нарушений нет».

ДИАГНОСТИКА

Проверить доступность

powershell
Invoke-RestMethod -Uri "$base/health"

При готовности сервиса: service = ChipTRick, status = ready. Проверка health не запускает анализ видео.

СитуацияЧто сделать
401Проверить API-ключ и заголовок X-API-Key.
404 при запросе заданияПроверить job_id, адрес сервера и используемый ключ.
415 / 422Проверить формат видео MOV и имя multipart-поля file.
413Превышен лимит размера: приложение принимает до 300 MB; внешний прокси может иметь более строгий лимит.
Сайт не открывается / 502 / 503Связаться с командой: проверить сервер, загрузку моделей, туннель и актуальный URL.

Все команды в инструкции предназначены для PowerShell, а не Bash, Swift или SQL. Полный ответ с base64-изображениями может быть большим — сохраняйте его в файл.

Что требуется для проверки
Публичный адрес, API-ключ и разрешённое к передаче видео. Вычисления выполняются на компьютере команды; запросы проходят через HTTPS-туннель Cloudflare. Доступность зависит от работы сервера и интернет-соединения команды.
