# ChipTRick

Локальное приложение для анализа кассовых видео: аккаунты, личная история, воспроизведение, однократные исправления, обучаемый временной классификатор и проверяемый выпуск версий.

## Доступ для жюри

**Веб-интерфейс:** [https://loan-side-novels-twiki.trycloudflare.com](https://loan-side-novels-twiki.trycloudflare.com)

1. Откройте сайт и выберите регистрацию.
2. Создайте обычный пользовательский аккаунт с собственными логином и паролем.
3. Войдите, загрузите видео и дождитесь результата. В личном кабинете доступны история, просмотр видео и события с таймкодами.

Также подготовлен обычный демо-аккаунт; данные входа можно получить у команды по контакту, указанному в форме сдачи. Его история общая для всех пользователей этого аккаунта. Для отдельной истории используйте собственную регистрацию. Административные функции доступны только команде.

Для **API** аккаунт и вход на сайт не требуются. Используйте заголовок `X-API-Key` с ключом из формы сдачи. [Пошаговая инструкция для жюри](docs/ChipTRick_Jury_API.html) — скачайте HTML и откройте в браузере.

Адрес актуален на 18.10.2026. Это временный Cloudflare-туннель; при его перезапуске адрес может измениться. При недоступности сайта свяжитесь с командой.

## Установка в новую папку

На текущем компьютере среда и веса уже установлены. Для новой установки с Python 3.12 и совместимой NVIDIA GPU:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools\download_models.py
.\.venv\Scripts\python.exe -m app.cli bootstrap
```

Загрузчик получает официальные RT-DETRv2, Qwen3-VL-2B и модель позы MediaPipe, сохраняет источники и проверяет контрольные суммы весов. Для анализа пользовательских загрузок исходный набор `videos` не обязателен; для воспроизведения оценки его нужно подключить вместе с разметкой. Состав фактически установленной среды сохранён в `runtime/installed-requirements.txt`.

## Что делает анализатор

RT-DETRv2 обнаруживает людей и предметы. Qwen3-VL-2B в 4-bit проверяет кадры и последовательности кадров. Код объединяет признаки по времени и сопоставляет их типам нарушений. Дополнительный небольшой классификатор обучается на CPU по сохранённым временным признакам; большие визуальные модели при этом заморожены.

Для X-1 проверяется возврат ранее принятых денег клиенту. Фиксированная последовательность всех действий не требуется. Для X-22 проверяется ключ, оставленный в замке после ухода от сейфа. Мелкие и перекрытые предметы могут оставаться неразличимыми.

Результаты: `violation`, `no_violation`, `needs_review`. Ошибка проверки, неполный анализ и неизвестный контекст не преобразуются в уверенный чистый вердикт. Уверенность — сила признаков, а не калиброванная вероятность.

## Обратная связь и обучение

Переключатель «Использовать это видео для обучения» выключен для новых загрузок. Для обучения нужны включённый выбор и одобренная разметка. Самостоятельный ответ модели не становится эталоном автоматически.

Исправление вердикта допускается один раз на загрузку и защищено ограничениями SQLite. Выбор использования для обучения можно менять отдельно. Выключение влияет на следующие обучения; действующие веса автоматически не забывают пример.

Интерфейс технически позволяет администратору размечать видео API и включать их в обучение. Однако полученный конкурсный кейс запрещает обучение на скрытых тестовых видео жюри: для таких видео выбор обучения должен оставаться выключенным. После использования любого примера для обучения он перестаёт быть независимым тестом.

Каждые 5 новых уникальных одобренных и разрешённых примеров запускают создание кандидата. Можно запустить вручную. Кандидат проходит групповую перекрёстную проверку: фрагменты и дубликаты одного видео не пересекают группы. Текущая модель продолжает обслуживать загрузки. Выпуск подтверждает администратор при прохождении проверки; ухудшившийся кандидат не выпускается. Старые ответы и их версии сохраняются.

## API

Ключ хранится в `runtime/api-key.txt`; передаётся в заголовке `X-API-Key`.
`POST /api/v1/analyze` принимает multipart-поле `file`. `GET /api/v1/jobs/{job_id}` возвращает `processing`, `done` или `failed`.
Для неопределённого результата API возвращает `failed/insufficient_evidence`, поскольку исходный контракт допускает только два окончательных вердикта. Такие случаи учитываются в качестве как необработанные, а не исключаются из оценки.

Сервис слушает localhost. На компьютере команды публичный HTTPS-доступ предоставляется через Cloudflare Quick Tunnel: `Start-Public.cmd`, проверка — `Public-Status.cmd`, текущая ссылка — `runtime/public-url.txt`. Адрес может меняться при перезапуске. Сервер и ноутбук должны оставаться включёнными. На новой машине предварительно установите официальный Windows amd64 `cloudflared.exe` в `runtime/tools/cloudflared.exe` по [инструкции Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/).

**Отдельная инструкция для жюри:** [docs/ChipTRick_Jury_API.html](docs/ChipTRick_Jury_API.html) — скачайте HTML и откройте в браузере. API не требует входа на сайт, но требует `X-API-Key`. В HTML нет настоящего ключа; ключ передаётся через поле конкурсной формы. Для проверки сайта нужен обычный аккаунт.

## Состав публикации и воспроизведение

В репозитории находятся исходный код, интерфейс, тесты, запускные скрипты и документация. `.gitignore` взят из исходного проекта ChipTrack. Локальная `.venv`, скачанные модели, `runtime` (база, медиа, логи, ключи и кандидаты) и банковские видео не публикуются. Установка среды и скачивание моделей описаны выше; при bootstrap на новой машине создаются собственные доступы. Существующая таблица разметки и реестр правил сохранены в data.

Рабочая версия на момент сдачи — `rules-2.0-acd1be0e`; обученные кандидаты не выпущены из-за ухудшения качества. Повторная установка может иметь другой отпечаток версии в зависимости от конфигурации и путей моделей. Опубликованный код воспроизводит алгоритм, но не переносит локальные аккаунты, историю и веса кандидатов.

На 40 уникальных видео разработки: recall наличия нарушения 71,4%, precision 88,2%; по критерию «тип + время» — 63,6% и 73,7%. Это известные разработчикам ролики, а не независимое подтверждение качества на новых камерах. Цель 90% не заявляется достигнутой. Детали и ограничения: [аудит кейса](docs/CASE_AUDIT_2026-10-18.md), [роли и обучение](docs/ROLES_AND_TRAINING.md).
